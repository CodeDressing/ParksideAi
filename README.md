# ============================================================
# ParksideAI
# Phase 5 Platform README
# ============================================================

ParksideAI is an AI-powered hospitality discovery and SEO platform built for:

```text
Parkside Tavern
Morristown, New Jersey
```

The system combines:

- conversational AI
- local restaurant SEO
- hospitality routing
- semantic discovery
- official guest guidance
- scalable AI architecture

ParksideAI is designed to guide guests to official Parkside Tavern resources while maintaining a privacy-safe hospitality experience.

---

# ============================================================
# SECTION 1 — CORE PLATFORM PRINCIPLES
# ============================================================

## Privacy-Safe Hospitality

ParksideAI is intentionally designed to:

- NEVER take reservations directly
- NEVER collect guest personal information
- NEVER store guest information
- NEVER process payments
- NEVER replace official hospitality platforms

Instead, ParksideAI routes guests to official Parkside Tavern destinations.

---

## Official Routing System

### Reservations
Guests are routed to:

```text
OpenTable
https://www.opentable.com/r/parkside-tavern-morristown
```

### Private Events
Guests are routed to:

```text
Tripleseat
https://parksidetavern.tripleseat.com/party_request/45075
```

### Restaurant Information
Guests are routed to:

```text
https://parksidenj.com/
```
